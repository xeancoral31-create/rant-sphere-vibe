# OutLoud Social

Create a full-stack social media web application called OutLoud, a modern and professional platform where users can freely share notes, rants, thoughts, opinions, daily experiences, and “MyDay” stories in real-time. The system must include a complete frontend, backend, database, authentication, admin panel, responsive UI/UX design, API integration, and professional system architecture. The platform should allow users to register and log in securely using email, username, password, Google authentication, and OTP verification. Users can create public or private profiles, upload profile pictures and cover photos, edit their bios, follow or unfollow other users, and manage account privacy settings. The homepage must contain a dynamic social feed showing posts, rants, images, videos, hashtags, trending topics, reactions, comments, shares, and reposts. Users should be able to create text-based rants, image posts, video posts, polls, anonymous posts, and “MyDay” stories that automatically disappear after 24 hours similar to stories in modern social media platforms. The MyDay feature should support image, video, text, music, stickers, reactions, viewers list, and reply functionality. Include real-time notifications for likes, comments, follows, mentions, replies, shares, and story interactions using WebSockets or Socket.IO. The messaging system must support one-on-one chats, group chats, emoji reactions, media sharing, seen status, typing indicators, and message deletion. Add an AI-powered content moderation system to detect toxic behavior, spam, hate speech, or inappropriate content. Include a trending algorithm that recommends viral rants, suggested users, and personalized feeds based on engagement and interests. The backend must use a scalable architecture with REST API or GraphQL, JWT authentication, secure middleware, role-based access control, and cloud storage for uploaded media. Use a professional database structure with tables for users, posts, stories, comments, reactions, messages, notifications, reports, hashtags, followers, and analytics. The admin dashboard must include user management, reports management, analytics charts, post moderation, content removal, account banning, engagement tracking, and system monitoring. The UI design should be modern, dark-mode supported, mobile responsive, animated, and inspired by modern social platforms with a clean and professional layout. Include pages such as Landing Page, Login Page, Register Page, Forgot Password Page, Home Feed, Explore Page, Trending Page, Notifications Page, Messages Page, Profile Page, Edit Profile Page, MyDay Viewer, Search Page, Settings Page, Admin Dashboard, and Error Pages. The system flow should include authentication flow, posting flow, MyDay flow, interaction flow, messaging flow, notification flow, moderation flow, and admin management flow. Use technologies such as Next.js or React for the frontend, Node.js with Express for the backend, PostgreSQL or MongoDB for the database, Prisma ORM, Tailwind CSS, Socket.IO, Cloudinary, Redis caching, and deployment using Vercel, Railway, or Docker. The project must follow professional full-stack development practices including MVC architecture, reusable components, API validation, rate limiting, secure session handling, optimized performance, lazy loading, accessibility, SEO optimization, and scalable deployment-ready structure.
